What never leaves the room

Workspace posts, pinned info and internal notes have no path to WhatsApp. A test in the package scans the send code and fails if one ever appears.
Messages to the customer go only through the case tools, from the hosting number, with the sender's name prefix, and only after the opt-out and number-health checks.
